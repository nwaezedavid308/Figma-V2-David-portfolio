# Portfolio redesign

This page overrides the previous master typography and palette, as requested.

Ubuntu 400/500/700 throughout; bold display headings, tight tracking, 12-column desktop and four-column mobile grid. Offset the second hero line to a column boundary. Prioritize design work before the biography.

Brand palette: deep navy #0D1B2A, primary blue #1A73E8, soft gray #E6E9EC, fresh green #2BC48A.

Light: white background, navy text, #435369 secondary text, soft-gray panels. Blue buttons use white text; on gray surfaces use #155FC0 for small blue links.

Dark: navy background, soft-gray text, #B4C3D0 secondary text, #152A3E panels. Green accents use navy when serving as a background. Navy glass overlays use white labels. Transparent effects never supply the only contrast boundary.

Two independent liquid glass image carousels: design work and graphics/brand work. Selected collections pin on desktop and map vertical movement to horizontal scrolling. Mobile and reduced motion use native scrolling plus buttons and keyboard navigation. The full collection uses native horizontal scrolling to avoid an excessively long pinned section.

Images are shown without cropping. Native modal dialogs show full artwork, support Escape, trap focus, and restore focus to their trigger. Themes persist in local storage with an early head script to avoid a theme flash.
